# Placement tests

English version english-2 is an approximate A1–C2 starting recommendation: 24 questions, four per band (two grammar/vocabulary, one reading, one listening). Each band needs at least three correct answers and all lower bands must meet that threshold. Below A1 is reported as beginner; C2 is the highest estimate. This is a small original question bank, not a calibrated CEFR exam or certificate. Teachers must review suitability and assess speaking. English, German, Spanish and Italian banks are available in code; four other languages remain unfinished.

Listening uses browser speech synthesis with an English voice and requires a user playback action. The client enables submission after all six passages finish. Voice quality/availability vary by device; unavailable audio provides an error and support guidance. Browser playback is a usability requirement, not anti-cheating verification. Correct answers and scoring remain in server code; submitted scores and student IDs are ignored. Repeating tests is allowed and retained as separate attempts.

Apply 202610030002_placement_results.sql after account onboarding in the verified preview database. Results are written only by the server service client. RLS permits own student results, active assigned teachers (assignment through lessons), and active admins. Students cannot insert/change their own score. Teacher detail page shows latest five attempts and overall plus skill scores. Results do not overwrite onboarding level or confer account/payment privileges.

Run npm test and npm run build -- --webpack. Placement tests validate band structure, scoring, foundation gaps, invalid answers, ownership, teacher assignment and forged client writes. Real browser audio playback and the complete Supabase save/read flow still require testing on the connected preview. Check desktop/mobile playback, interrupted audio, denied audio support, validation, save failure, returning result history and assigned teacher access before launch.

## Separate progress checks

/progress-test uses english-progress-1: 24 different questions with the same six-band skill structure. Apply 202610030003_progress_assessments.sql after placement_results. Existing rows default to placement; progress attempts are separate, append-only through the server action. Retakes are allowed at any time, suggested after several months or a package. No automatic reminder/email is sent. Teacher history includes both kinds separately. Compare first and latest progress scores only within the same test version, never as a calibrated difference against the different placement bank. Repeated exposure to a fixed bank can improve familiarity; the UI states that the teacher must verify changes. More alternate banks and professionally calibrated audio remain future work. Mobile navigation scrolls horizontally to fit additional routes.

## German tests

German placement/progress banks each contain 24 original questions (48 distinct prompts) with the same A1–C2 skill structure and approximate scoring. The language picker supports English, German, Spanish and Italian; the remaining four languages are unfinished. Server accepts only en/de/es/it and chooses the corresponding language, bank, version and answer key. German listening requests de-DE speech synthesis; actual device voice support requires preview testing. Apply 202610030007_german_assessments.sql; German questions stay hidden when readiness RPC is missing. Same-language progress comparisons are filtered by both language and version, and success return links retain the selected language. These banks remain uncalibrated starting estimates and need teacher content/level review, not CEFR certification.

Assessment form reliability: selected radio answers persist across returned save errors and network failures for retry. Switching language/version remounts the form and clears the previous bank's answers/listening state. Cancelled, replaced, interrupted and stale speech callbacks cannot mark a clip fully heard; only a current successful end counts. Playback exceptions show retry feedback, and success/unmount stops audio. Mock audio regression checks do not prove real device voice availability.

Spanish placement/progress: 24 original questions each, with distinct prompts and listening passages, four questions per A1–C2 band (two grammar, one reading, one listening). Same approximate foundation-aware scoring and separate language/version comparisons apply. Voice request es-ES; actual device voice availability requires preview testing. Apply 202610030010_spanish_assessments.sql before enabling the forms; the readiness RPC hides them until storage supports Spanish. Teacher review and calibration remain outstanding. French, Portuguese, Russian and Turkish banks are still unfinished.

Italian placement/progress: 24 original questions each, separate prompts and listening passages, covering A1–C2 grammar, reading and listening. Voice request it-IT.
