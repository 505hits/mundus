# Russian and Turkish placement drafts

These48 original draft questions are not imported into the application, offered to students, or used to store scores. Each language has24 items: four per provisional A1–C2 band, with12 grammar,6 reading and6 listening items. Answer keys are staff review material, not browser payloads.

Before release, a qualified teacher must check every prompt, answer and distractor for grammatical correctness, natural wording and a single defensible answer. Check that listening answers follow the passage, reading passages test understanding rather than guessing, and higher-band items have credible distractors. The provisional band labels are not validated CEFR classifications: short passages and obvious distractors may underestimate difficulty. Revise, pilot and review score thresholds before enabling.

Separate progress banks are still required; do not reuse these placement questions as a supposedly independent progress measure. Audio is proposed text only; Russian ru-RU and Turkish tr-TR device playback remain untested. Future activation requires catalog, server validation and storage/readiness support plus ownership/privacy tests. No migration or feature activation accompanies these drafts.
